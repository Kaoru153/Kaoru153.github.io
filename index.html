コンペ支援ツール

ds-hub

KaggleSIGNATEダッシュボード

参加するコンペを台帳にまとめ、開催中のコンペ、自分の順位、締切、コンペごとのリポジトリの状況を集めて一つの画面で見られるようにした管理拠点。参加する前に、開催中のコンペを絞り込んで比べることもできます。

kaggle-manage

KaggleClaude Code スキル

Kaggle 公式の CLI を実際のサービスで試して挙動と落とし穴を記録し、データの取得、提出、Notebook の実行までを Claude Code のスキルにまとめました。

kaggle-meta-research

Kaggleデータ分析Claude Code スキル

Kaggle 公式の公開データ Meta Kaggle を使い、シミュレーション系・最適化系コンペの上位解法と、386 コンペ・約 53 万チームの最終提出の選び方を調べて、コンペの進め方の手引きにまとめました。

概要 プライバシーポリシー

Claude 作業部屋

Claude Codeダッシュボード

Claude Code がいま何をしているかを、ブラウザで眺められるダッシュボード。セッションごとの作業の様子、実行中のコマンド、CPU・メモリ・GPU の使用状況、作ったファイルを一覧でき、操作の許可や質問にも画面から答えられます。

予測・分析

競馬の着順予想 AI

機械学習開発終了（2026年8月）

JRA・地方競馬の着順を予想する AI。黒字に見えた戦略が、データの読み込みの不具合で答えが混ざった（リークした）結果だったと分かり、約 2,000 通りの条件を並べ替え検定と時系列分割で検証し直した結果、「勝てる条件は見つからなかった」と結論して開発を終えました。

競艇の着順予想 AI

機械学習

競馬版で作った検証の仕組みを引き継ぎ、ボートレースのデータ収集から、予測モデル、オッズに表れる市場のずれの分析までを作りました。

FX テクニカル分析ハンドブック

教材可視化

チャートの見方、テクニカル手法、指標を図解で体系的にまとめた教材と、その図をすべて生成する Python のコード。線を引いて巻き戻しながら練習できるチャートアプリや、設定ファイルに書いた手法の過去検証もあります。値動きの予測や売買の推奨はしません。

パチスロのデータ分析

データ分析可視化

店舗の公開データ（機種ごとの日別の平均差枚など）を集めて、曜日や特定日ごとの傾向を集計・可視化し、指定した日にねらい目の機種をレポートにするシステム。
