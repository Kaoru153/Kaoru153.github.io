プライバシーポリシー

制定日: 2026年11月7日

このポリシーは、Kaoru153（以下「開発者」）が作成した Gmail 整理ツール「gmail-management」（以下「本ツール」）が、Google アカウントのデータをどう扱うかを説明するものです。

1. 取得するデータ

本ツールは、利用者が許可した Google アカウントから、Gmail API を通じて次のデータを取得します。

  • Google アカウントのメールアドレス（どのアカウントかを見分けるため）
  • メールの ID とラベル、ヘッダーのうち送信元・件名・日付
  • ラベルとフィルタの設定

メール本文と添付ファイルは取得しません。

2. 利用目的

取得したデータは、利用者がコマンドで指示した次の操作のためだけに使います。

  • 検索結果の表示
  • 未読メールを既読にする
  • 送信元ごとのラベル付けと、振り分けフィルタの作成
  • ラベルとフィルタの削除

広告、データの販売、信用度の判定には使いません。AI・機械学習モデルの学習にも使いません。

3. 保存場所と保存期間

本ツールは利用者の PC 上で動き、データは次の場所にだけ保存します。

  • tokens/: 認証情報（OAuth のアクセストークンとリフレッシュトークン）
  • data/<アカウント>.sqlite3: メール ID と送信元（アドレスと表示名）の対応表。2 回目以降の取得を速くするためのキャッシュ
  • data/backups/: 既読にしたメールの ID の控え（元に戻すため）

これらは利用者が削除するまで PC 上に残ります。開発者のサーバーや第三者のサービスには送信も保存もしません。

4. 第三者への提供

取得したデータを第三者に提供・販売・転送することはありません。利用者本人以外の人がデータを読むこともありません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールが Google API から受け取った情報の使用と他のアプリへの転送は、限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

gmail-management's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. データの削除とアクセス権の取り消し

  • PC 上の tokens/ と data/ を削除すると、本ツールが保存したデータはすべて消えます。
  • Google アカウントの「サードパーティ製のアプリとサービス」から、本ツールへのアクセス権をいつでも取り消せます。

7. このポリシーの変更

内容を変える場合は、このページを更新し、改定日を記載します。
